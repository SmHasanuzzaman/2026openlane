# CMOS Inverter OpenLane ASIC Flow

This repository contains the RTL design, testbench, and physical implementation flow for a standard CMOS Inverter using the OpenLane 2 / OpenROAD ASIC design flow.

## 📌 Project Overview
- **Design:** CMOS Inverter (`inverter`)
- **Language:** Verilog HDL
- **Target Flow:** OpenLane 2 (RTL-to-GDSII)
- **Tools Used:** OpenROAD, Yosys, Icarus Verilog, GTKWave, Vivado
